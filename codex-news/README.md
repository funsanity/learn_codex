## 建议记录字段

每个事件建议记录：发生时间、核心变化、影响范围、关键指标、来源及可信度、与 Codex 工作流的关系、待验证问题、后续更新。

## 更新规则

1. 优先引用官方原文；指标必须保留评测名称、设置、模型版本和是否使用特定 harness。
2. 不把模型能力、工具能力、运行外壳（harness）和生产防护的结果混为一谈。
3. 对价格、可用性、默认开关和 API 参数标注“截至日期”，后续变化直接在事件页追加时间线。
